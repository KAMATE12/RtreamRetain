# Sprint 1 reading worksheet

Book: Dan Olsen, The Lean Product Playbook. Read selected sections about target customers, underserved needs, value proposition, and MVP feature scope in your own copy. Reading the entire book is not required.

## Concepts to investigate

The author's public overview presents a process that starts with customers and their needs, then defines value and MVP scope before prototyping and testing. For StreamRetain, this means deciding what a retention manager needs to learn before building charts.

## Apply to StreamRetain

- Target user hypothesis: a retention manager, rather than a viewer watching films.
- Need hypothesis: identify which customer groups have higher cancellation rates.
- Value proposition: make patterns understandable and support proposed follow-up actions.
- MVP choice: import, indicators, segment comparisons, and action tracking.

These are project hypotheses. They have not been validated by IVI customer research.
