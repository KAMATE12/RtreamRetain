## Definition of Done

A task meets its acceptance criteria, its result is checked, relevant changes are committed and pushed, and the README is updated where necessary. The student can explain the result. For software tasks, relevant tests/build checks pass. For planning or reading tasks, the stated document and evidence are sufficient.
